# CGV 용산아이파크몰 IMAX 예매 오픈 알리미

GitHub Actions로 15분마다 자동 실행되면서, CGV 용산아이파크몰 예매 페이지에서
"오디세이" 새 상영 날짜가 열리면 [ntfy.sh](https://ntfy.sh) 푸시 알림을 보내줍니다.
컴퓨터를 켜둘 필요가 없습니다 — GitHub 서버가 대신 돌려줍니다.

## 어떻게 동작하나요

CGV 예매 페이지는 상단에 "오늘 16 / 월 17 / 화 18 ..." 같은 날짜 탭이 나열되어 있고,
탭을 클릭해야 그 날짜의 상영시간표가 나타나는 구조입니다 (영화 이름 옆에 날짜가 붙어있는
구조가 아닙니다). 스크립트는 비활성화되지 않은 날짜 탭을 순서대로 모두 클릭해보면서,
각 날짜의 "오디세이" IMAX 상영시간표 안에서 **예매 버튼이 실제로 활성화(클릭 가능)된
회차가 있는지**를 DOM에서 직접 확인합니다. 단순히 "IMAX관" 글자가 화면에 보이는 것만으로는
True로 치지 않고, 매진/예매종료/오픈 전이라 버튼이 비활성화(aria-disabled="true")된
회차만 있으면 False로 취급합니다. 캘린더는 매일 하루씩 밀리기 때문에, 새로 나타나는
먼 날짜에서 예매 버튼이 처음 활성화되는 순간을 "새 날짜 오픈"으로 판단해 알림을 보냅니다.

이 방식은 2026-08-16에 실제 사이트에 접속해서 화면 구조를 직접 확인하고 검증한
것입니다. 다만 CGV가 화면 구조(클래스명 등)를 바꾸면 다시 손봐야 할 수 있습니다.
Actions 탭 로그에 "날짜 탭을 하나도 찾지 못했습니다" 같은 메시지가 보이면 알려주세요.

첫 실행에서는 알림 없이 현재 상태만 기준선으로 저장합니다. 그 다음 실행부터
새로 열리는 날짜가 있을 때만 알림이 옵니다.

## 설치 순서

### 1. ntfy 앱 설치 & 토픽 구독
1. 휴대폰에 **ntfy** 앱을 설치하세요 (iOS/Android 무료, 검색: "ntfy").
2. 앱에서 "+"를 눌러 새 구독(subscribe) 추가.
3. 아무도 못 맞출 만한 임의의 토픽 이름을 정하세요. 예: `cgv-yongsan-a7x92k`
   (ntfy는 토픽 이름을 아는 사람이면 누구나 알림을 볼 수 있어서, 너무 뻔한 이름은 피하세요.)
4. 그 토픽 이름을 구독해두면 끝. 아래 3번 단계에서 같은 이름을 씁니다.

### 2. GitHub 저장소 만들기
1. github.com에서 새 저장소(Repository)를 만드세요. Public으로 해야 Actions 무료 시간 제한이 없습니다.
2. 이 폴더 안의 파일들(`check.py`, `.github/workflows/check.yml`, `state.json`)을
   그 저장소에 그대로 업로드하세요. (웹에서 "Add file → Upload files"로 드래그해도 됩니다.)

### 3. 알림 토픽을 저장소 Secret으로 등록
1. 저장소 페이지 → Settings → Secrets and variables → Actions → New repository secret
2. Name: `NTFY_TOPIC`
3. Value: 1번에서 정한 토픽 이름 (예: `cgv-yongsan-a7x92k`)
4. 저장.

### 4. Actions 활성화 & 테스트 실행
1. 저장소의 "Actions" 탭으로 이동 → 워크플로우 활성화(Enable) 버튼이 보이면 눌러주세요.
2. "CGV Yongsan IMAX Checker" 워크플로우 선택 → 오른쪽 "Run workflow" 버튼으로 한 번 수동 실행.
3. 실행이 끝나면 로그를 열어서 "새로운 날짜 없음" 또는 "새 날짜 발견" 같은 메시지가
   정상적으로 찍히는지 확인하세요.
4. 이후로는 15분마다 자동으로 돌아갑니다.

## 참고
- GitHub 무료 스케줄 실행은 정확히 15분마다가 아니라 몇 분 정도 지연될 수 있습니다.
- 저장소에 60일 이상 커밋이 없으면 GitHub이 자동으로 스케줄을 비활성화합니다.
  (이 스크립트는 매번 state.json을 커밋하니 문제없이 계속 돌아갑니다.)
- 다른 영화를 확인하고 싶으면 `.github/workflows/check.yml`의
  `MOVIE_KEYWORD: "오디세이"` 부분만 바꾸면 됩니다.
